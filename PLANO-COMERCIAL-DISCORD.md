# Shadow Optimizer como produto Shadow Games

## Venda pelo Discord

O painel já está preparado para usar o Discord como loja. Edite `store.json` e troque `https://discord.gg/SEU-CONVITE` pelo convite real do seu servidor. Os botões de compra, suporte e Discord passam a abrir o mesmo canal ou servidor.

## Estrutura recomendada do Discord

Crie canais separados para `compras`, `suporte`, `atualizações`, `tutoriais` e `feedback`. Mantenha um canal com regras claras sobre licença, atualizações, suporte e reembolso. Use cargos para diferenciar teste, cliente, revendedor e suporte.

## Licença do produto

Para uma versão comercial, o programa deve ter uma licença simples e transparente. A licença pode ser vinculada a um código, ao usuário do Discord ou a uma conta própria. Evite coletar identificadores de hardware irreversíveis sem informar claramente o motivo e sem oferecer suporte para troca de computador.

O ideal é permitir:

- modo demonstração com funções de análise;
- ativação pelo Discord ou por uma página própria;
- quantidade de computadores permitida;
- desativação de uma máquina antiga;
- renovação e atualização;
- modo offline temporário;
- tela para consultar validade e versão.

## Não recomendo

Não coloque senha ou token do Discord dentro do aplicativo. Não use o token de um bot no cliente. Não esconda mineração, telemetria ou coleta de dados. Não bloqueie o Windows nem force alterações irreversíveis para impedir cópia.
